# Recall support

[Setup guide](../SETUP.md) · [Paper walkthrough](../demos/PAPER.md) · [Privacy](../PRIVACY.md)

For a question or reproducible problem, [open an issue on GitHub](https://github.com/justslee/recall/issues). Include the app version, operating-system version, steps you took and what you expected. Check the issue for private content before posting; GitHub issues are public.

TestFlight testers can also send feedback through TestFlight. Review any attached screenshot or diagnostics first. Never include API keys, pairing codes, assistant capabilities, profile backups or private learning notes.

## Common questions

**Do I need an account?** No Recall account is required for local study or blank iPad writing. Optional assistant/provider features use the accounts you choose to configure.

**Does my iPad need the Mac all the time?** Writing and saved work remain available offline. Transfer needs the paired Mac receiver and Recall Pad active on the same reachable local network. iPadOS may suspend the app in the background.

**The Mac isn't appearing.** Keep both apps open, use the same local network and confirm Recall's companion is enabled. Check local-network permission in iPad Settings and any Mac firewall prompt. Generate a fresh pairing QR if the previous one expired. Never disable authentication or install an arbitrary system certificate.

**How do pages reach my tutor?** Use the Mac Tutor Pad tray's explicit **Copy page**, paste in your chosen chat and press Send yourself. A separately configured paper-learning connection can expose selected submitted pages to the original assistant session when you ask it to read them. Receipt on Mac does not mean feedback is ready.

**I deleted a sheet but still see its image elsewhere.** Deletion removes that iPad sheet and its queued local work. Copies already received on Mac, shared, exported or attached to a conversation remain at those destinations.

**Can I get AI feedback without an OpenAI API key?** Recall's separate Mac handwriting assessor requires your API project, internet, explicit consent and billing. Tutor Pad can instead be used beside the assistant you already have; that client's usual access and billing apply.

For a security vulnerability, use the [private reporting instructions](../../SECURITY.md) rather than a public issue. A private contact address for feedback/review forms is selected by the owner in App Store Connect; these public docs do not disclose account contact information.
