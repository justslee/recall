# Concept

Explain first at the depth the learner needs, with a definition, mechanism and concrete example. Use recall-visuals when a visual materially improves the explanation. For enabled Recall capture, follow [active reading](../recall-source/references/active-reading.md) and end with a brief local receipt.

When the user requests KB publishing or has agreed to it for the learning session, follow [knowledge operations](../recall-source/references/knowledge.md). Search names and aliases in the selected source before writing. Reuse an exact match, preserve user prose and sources, and link genuinely related concepts. Report KB and Recall outcomes separately.
