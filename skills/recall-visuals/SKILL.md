# Visuals

Read [quality.md](../recall-source/references/quality.md) and [visuals.md](../recall-source/references/visuals.md). Identify what the learner should notice, then compose the actual regions, marks, labels and controls around that relationship. Use meaningful spatial layouts, restrained semantic accents and coordinated state explanations; generic boxes or decorative animation are not the visual standard. Follow the reference's responsive, keyboard, reduced-motion and playback/reset guidance. Verify representative/boundary values independently, test every control, and inspect the rendered card in both themes. Preserve explicit Load and answer-reveal boundaries, including the reader's permission step for inbox imports. A simple definition can have a visual example; it does not automatically need a simulator.
