# Learn

Read ../recall-source/references/quality.md and knowledge.md. Establish the learner's goal and prior knowledge from context. Search the KB; propose prerequisite concepts and a manageable sequence. Teach one useful unit at a time with examples, then test understanding. Save the path and concept relationships in the configured KB; preserve existing entries. Use recall-concept, recall-deep-dive and recall-cards where appropriate. Log only material actually discussed, not every future lesson in the plan.
