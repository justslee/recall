# Active reading to Recall

After a substantive reading question, answer in context, then complete the opted-in learning loop before ending the response. Batch closely related objectives at a natural checkpoint. This is an assistant-executed workflow. The optional catch-up scanner is separately enabled and scoped; read inbox.md for queue handling.

1. Search the configured KB and Recall independently, using names, aliases and source identity. Inspect candidate prompts and answers. A KB page is not a card; a matching title does not establish objective coverage. Reuse a suitable ready, unsuspended card and its stable identity.
2. Evaluate concept, math and coding suitability separately, even for an existing concept. Coding should test implementing, tracing or debugging; math should test a meaningful quantitative application. Search existing variants by conceptId and objective before creating a supplement. Do not force all formats or expand into unrelated lessons.
3. Queue genuinely missing objectives with `recall inbox add FILE` (empty cardIds, or needsAuthoring for a supplement). Fill them through recall-cards and its validation/safe import workflow when preparing the inbox. Preserve existing content and independent review history. If an exercise is blocked, record the specific gap instead of claiming it exists.
4. Capture the actual discussed objective, source and context using recall-self-test. Link verified reused/new card IDs. Generated exercises are practice opportunities, not evidence the learner solved them. Preserve stable capture IDs/timestamps on retries. Never rate or start a test, infer mastery or change schedules from exposure.
5. Use `recall cards link CARD_ID` to return a verified Markdown link. Report “New concept”, “Existing concept”, or “New coding/math exercise”, plus “added to today's Self Test” only after successful capture/linking. Report unchanged retries as already captured. Include the KB link when available and state partial failures separately.

The packaged Mac app opens `recall://card/<encoded-id>` with answers hidden. Links refer to card identities in the receiving app's local library; they do not transfer cards or select a different data profile. If a chat client blocks custom URLs, provide the exact title for Library search; open via the OS only when requested. A missing KB connector does not block local Recall capture. Honor opt-out and do not log routine operations, raw transcripts or assistant-only implementation.
